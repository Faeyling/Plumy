# ANIMATIONS_TODO — Termes sans `animationId`

Ce fichier recense tous les termes qui n'ont pas encore d'`animationId` assigné.
Le champ `animationId` est requis pour activer le quiz de type **Reconnaissance visuelle** sur un terme.

## Statut global

- **Termes avec animationId** : 0 / ~220
- **Termes sans animationId** : ~220 / ~220
- **Quiz reconnaissance-visuelle désactivé** pour tous les termes jusqu'à l'ajout des IDs.

> Les unités 2, 3, 5 et 8 déclarent `reconnaissance-visuelle` dans `quizDisponibles` — ce type de quiz sera disponible dès que les `animationId` correspondants seront renseignés.

## Comment assigner un animationId

Dans le fichier du terme concerné, ajouter le champ :

```typescript
animationId: 'arabesque-classique-v1',  // identifiant de l'animation Lottie/Rive/vidéo
```

Une fois l'`animationId` présent, le terme devient éligible au quiz **Reconnaissance visuelle** sans autre modification.

> Note : `reconnaissance-visuelle` dans `quizDisponibles` d'une unité est une déclaration d'intention. Le moteur de quiz doit filtrer les termes disponibles par présence d'`animationId` au moment de la génération des questions.
